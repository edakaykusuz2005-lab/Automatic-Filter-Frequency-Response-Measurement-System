# Automatic Filter Frequency Response Measurement System

Graduation Design Project

## Description
This project presents an automated system for measuring the frequency response of analog filters using an STM32F407 microcontroller, AD9833 DDS signal generator and a Qt-based PC interface.

## Hardware
- STM32F407G Discovery
- AD9833 DDS Module
- Sallen-Key Low-Pass Filter
- Oscilloscope

## Software
- STM32CubeIDE
- Qt Creator
- Proteus
- LTspice

## Features
- Automatic frequency sweep
- RMS measurement
- Gain calculation
- Bode plot generation
- USB CDC communication
